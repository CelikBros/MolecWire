## Proposed direction for MolecWire

The selected direction is a **Go modular monolith**, with separate API and worker processes, and **PostgreSQL**. For a concrete stack candidate, use Kapsora's demonstrated **chi, pgx, sqlc, and golang-migrate** conventions, subject to architecture review. The proposed MolecWire choice is **React and Vite** for the newsroom frontend and Go `html/template` for public pages; this is a project recommendation, not a reference-project finding. Keep AI behind a narrow Go adapter; a Python service has no established need unless a specific Python-only capability and measured benefit are demonstrated. Do not add Redis by default. These are recommendations, not claims that Kapsora's entire architecture should be copied.

Every MVP publication requires a human decision bound to the exact immutable revision and language; an edit invalidates approval. Keep credibility, corroboration, completeness, and publication readiness separate. Check source permissions before retrieval and generation, expose only published revisions in public reads/search, and retain auditable correction and retraction history under a defined privacy and retention policy.

**Technical evidence limits:** the served client bundle contains React route components, a Vite dependency-map helper, a same-origin `/api` client and a static-page component that requests `/pages/{name}?lang=...`. These are public client artifacts, not backend source or proof of the full development stack. Backend language, database, queue, actual model deployments and hosting topology remain unknown. Provider/data-processing behavior and editorial oversight now have publisher declarations, while enforcement, licensing permissions, evidence-assessment quality, correction history and news accuracy remain unverified.

**Assessment against the charter:** Kantan is useful as a public news-product reference for concise presentation, attribution, AI disclosure and explicit processing-policy descriptions. MolecWire requires claim-to-evidence links, separate uncertainty assessments, approval bound to immutable review packages and visible correction/retraction notices. This review establishes no comparative superiority or absence of those controls in Kantan. Keep the MolecWire acceptance requirements when adopting similar feed/summary patterns. Do not copy articles, design assets or source code, and do not infer republication permission from public availability.
